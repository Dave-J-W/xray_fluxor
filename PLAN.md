# PLAN: xray_fluxor, phase 1 (MonP counts → photons/s; physics and hardware)

Approved by the user on 2026-11-12 in the planning session. The full approved text is in the session plan file, and this file is its tracked copy.

## Scope
- **MonP only.** The reference plane is the MonP exit: after the plates, before the Kapton exit window.
- **Deliverables:**
  - `physics_note.md`
  - a researched-constants database with saved queries (`data/queries/`)
  - a measurement checklist
  - `TODO.md` of deferred items
- **Out of scope (later addenda):**
  - MonC and other chambers
  - Kapton windows and the air path
  - software
  - dark-drift study
  - MonP/BPM error-state monitor

## Scope guard (counts as drift: stop and ask)
- Any write to EPICS PVs or hardware. Changing SR570 gain or offset always needs the user (CLAUDE.md).
- Building conversion software, IOCs or utilioc slots.
- Buying or recommending hardware purchases beyond what the note estimates.
